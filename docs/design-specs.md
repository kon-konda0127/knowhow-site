# デザイン仕様書 10案

## パターン選定の考え方
コンテンツはAI開発・ダンス・ランニングという技術と趣味が混在するため、
「技術ブログらしさ」「読みやすさ」「スマホでの快適さ」を軸に評価する。

---

### パターン1：Notion風
**コンセプト**: ミニマル・白黒・テキスト中心
**配色**: 背景 #ffffff、テキスト #111827、アクセント #2563eb
**フォント**: 見出し Inter/Noto Sans JP、本文 同左（サイズ差で階層を表現）

## 実装する3案の選定

**選定結果：パターン3（Linear/ダーク）、パターン2（Zenn/青白）、パターン8（マガジン/インパクト）**

### 選定理由
- **最大コントラスト**: 黒背景 vs 水色白 vs 白黒直角で三者が明確に違う
- **AI開発コンテンツとの相性**: Linear風は技術者受け最高、Zenn風は読みやすさ重視、マガジン風はキャッチー
- **スマホ対応**: いずれも縦1列レイアウトに落とせる

| folder | 対応パターン | キャッチフレーズ |
|---|---|---|
| pattern-a | Linear風（ダーク） | プロダクト感・洗練 |
| pattern-b | Zenn風（青白） | 読みやすさ重視 |
| pattern-c | マガジン風 | 視覚インパクト |
