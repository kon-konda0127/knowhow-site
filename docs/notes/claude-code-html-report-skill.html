# なぜ重要か

これを読むと、AIの資料の見た目を「センス」ではなく「作法書」で安定させる方法と、外部のスキルを入れる前に何を見るかが分かる。

AIの生成物は放っておくと没個性なテンプレ見た目（いわゆるAI slop）に収束する。この問題への、具体的で再現可能な対策例である。

# しくみ（なぜ効くか）

  • スキルとは、特定の頼み方をした瞬間だけAIが読み込む「作法書」
  • この html-report-design スキルは「HTMLで出して」「レポートにして」と言った時だけ働く
  • 中身は「禁止と強制」の組み合わせ。禁止するのは枠線・グラデーション・絵文字（AIが多用しがちな装飾）
  • 強制するのは、完成済みCSSを使うことと、各セクションを「見出し→結論1文→根拠」の順にすること
  • 図解は5つの型（矢羽根/ロードマップ/フレームワーク表/バブル/滝グラフ）から選ばせ、自由に描かせない
  • 配色は脇役グレー＋主役の濃紺1色。アクセント色だけ会社カラーに差し替え可能
  • 効く理由: 「センス良く」という曖昧な指示ではなく、判断基準を作法書として渡すから毎回同じ品質が出る

# うちの体制ではこう使う

  • 「AI生成UIは放っておくとテンプレ的な見た目に収束する」問題は、当サイトの開発でも実際に直面した
  • 対処として、チーム規程に「配色・余白・タイポグラフィの判断基準を毎回明示的に適用する」というルールを入れている
  • このスキルはその「判断基準の明文化」を資料デザイン領域でパッケージ化したもの。発想は同じで、対象がUIか資料かの違い
  • 使い方は「HTMLで資料にして」「レポートにして」と言うだけ。アプリの画面づくりには発火しない（後述の条件2）

# 入れる前に見た3点と、その結果（2026-08-16）

2026-08-15、Xで紹介されていた急上昇中のOSSをAIが推奨し、コードを読むと暗号資産のウォレットを盗むマルウェアだったことがあった。同梱の説明書には「アップロードしない」と書いてあったが、事実と違った。

それ以来、外部のスキルやパッケージは入れる前に3点を見る決まりにしている。調べる時もコードは実行せず、GitHubのAPI経由の読み取りだけで行う。この手順を本番で使ったのは、このスキルが初めてだった。

  • ①同名の複製でないか: 同名のリポジトリはGitHub全体で1件のみ。forkではなく、作成は2026-07-21、ライセンスはMIT、スターは53（2026-08-17時点）。本家と偽物を取り違えようがなかった
  • ②ネットワーク送信・外部プロセス起動が無いか: 送信・外部プロセス・危険パターンの走査は検出0件。書かれていたURLは、作者のGitHub・同じリポジトリ・作者のXの3件だけ
  • ③インストール時に勝手に動くフックが無いか: インストール時に動くファイル（package.json等）は存在しない

そもそも中身は、文章ファイル（.md）4つと見本のHTML1つで、実行できるコードは無かった。作法書の本体382行は全文を読み、原則5つ・禁止事項8つ・品質チェック11項目といった規範に終始していて、外部送信や認証情報の読み取りを促す指示は無い。軽微な所見が1件だけ——「確認の質問はせず、既定の濃紺で進めてよい」という一文——あったが、アクセント色1つの選択に限る話なので記録に残すだけにした。

さらに監査役（別のAI）が独立に、GitHubから原本を取り直して差分を取り、目に見えない隠し文字（ゼロ幅文字）の検査まで追加で行い、10基準すべて合格だった。

# 導入した。ただし条件2つ

  1. 紹介されていた導入コマンド（npx skills add …）は使わない: これは skills という第三者のnpmパッケージをその場で実行する経路で、審査した本体とは別物が動く。中身が文章とHTMLだけなら手で置けるので、GitHubのAPI経由で取得したファイルを手動で配置し、取得元と同一であることをsha256（ファイルの指紋）で確認した
  2. 適用範囲を配布資料専用に絞る: 元の説明では「あらゆるHTML出力」が対象だった。当チームはアプリの画面を単一のHTMLで作るので、そのままだと画面づくりにまで発火する。説明文2箇所を書き換え（削除2行・追加11行。MITライセンスなので改変できる）、規範の実体は無改変

# よくあるミス・落とし穴

以下は筆者の考察。

  • スキルなしで「HTMLで出して」と頼むと枠・グラデ・絵文字まみれになる
  • 紹介されたインストール用の一行を、中身を見ずにそのまま実行する（審査した本体とは別のものが動く経路になりうる）
  • スキルの適用範囲を確かめずに入れ、意図しない場面（アプリの画面づくり等）まで発火させる
  • Claude Code専用ではない（ChatGPT派はSKILL.mdの中身をコピペしても動くとされる ※要確認）
