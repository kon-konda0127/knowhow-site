Codex subagent のモデルルーティング（model-router）

カテゴリ: AI開発 > Codex活用 更新: 2026-08-09 📖 約2分で読めます
#Codex #subagent #モデル選択 #コスト最適化

# なぜ重要か

AIコーディングでは、全タスクを最上位モデルに任せるとコストが膨らみやすい。タスクの重さに応じてモデルを自動で使い分けられれば、品質を保ったまま利用コストの構造そのものを変えられる。

# ポイント

  • model-router というツールで Codex の subagent 機能を拡張できる
  • タスクごとに異なるモデルを使い分けられる（Opus等の上位モデル ↔ DeepSeek等の軽量モデル）
  • 重い判断・設計は上位モデル、定型的なコード生成は軽量モデルに振り分け
  • コスト構造そのものが変わる発想

# インストール手順

  • model-router をインストール
  • subagent のモデル設定で「選択したモデルすべて」を有効化
  • 設定を保存して完了

# よくあるミス・落とし穴

  • これまでは全タスクに同じ最上位モデルを使うのが普通だったが、それはコスト過多になりやすい
