太ってた。8年分の体重記録を見返して、最初に気づいたこと

太ってた。ずっと薄々わかっていたけれど、数字で見たことはなかった。

⏱ 30秒でわかるこの記事
  • アラフォー。2026年3月にダイエットを始めた。まず約8年分（170回）の体重記録を全部見返した
  • 分かったのは、開始時点が約8年間の平均より約5kg重かったこと。太ったというより「重い状態が続いていた」
  • 3月からの変化量は約-9kg。最も重かった日と比べると約-11kg

なぜ記録から始めたか

ダイエットを始めようと思ったとき、最初にやったのは運動でも食事制限でもなかった。

iPhoneのヘルスケアに、2018年9月からの体重が残っていた。まずそれを全部見返した。（この記事で「8年分」と書いているのは、正確には2018年9月からの7年11か月。以下は丸めて「約8年」と表記する）

理由は単純で、いま自分がどこにいるのか分からないまま走り出しても、続かないと思ったから。

記録をグラフにしてみた

見返して分かったのは、「太った」というより「平均より重い状態が続いていた」ということだった。

グラフは2022年5月から2026年8月まで。それ以前に残っていた記録は2018年の1回だけで、線にすると実態より滑らかに見えてしまうので省いた（平均の計算には約8年分すべてを使っている）。

2022年の秋に一度下がって、そこから2年かけてじわじわ戻っている。2026年3月はその延長線上で、約8年間の平均より約5kg重いところにいた。

気づいたこと

数値そのものより、「平均からどれだけ離れているか」で見たほうが分かりやすかった。太った時期と戻した時期が、はっきり分かれて見える。

もうひとつ変わったのが、体重計に乗る回数だった。

3月は月4回。4〜5月に月10回・19回まで増え、6月以降は月6〜8回で続いている。

ピークは5月で、6月に大きく落ちたあとは月6〜8回で落ち着いている。それでも、まったく測らなかった時期には戻っていない。

測る頻度は効いたのか（分からない）

毎日乗ると、前の日の食事との関係が見えるようになった感覚はある。記録を見ると、こうなっている。

  • 頻度が上がった4月以降、体重が戻った月は一度もない。5か月続けて下がっている
  • ただし減り幅そのものは月を追って小さくなっている（前月比 -2.13kg → -2.45 → -1.57 → -1.42 → -1.28）

同じ時期に食事の見直しとランニングも始めているので、測る頻度が効いたのかどうかは、このデータからはどちらとも言えない。切り分けて測っていないからだ。ここは実感として書いておくに留める。

この記事の限界

  • 体重の実数値は載せていない。変化量と、平均からの離れ方だけを書いている
  • 効果には個人差がある。これは一個人の記録であって、方法の推奨ではない
  • 記録が2か月以上ない期間がある。グラフではその区間の線をつないでいない（無いデータを想像で埋めていない）

結局、何をしていたか

  • 約8年分の記録を全部見返して、開始時点の位置を確かめた
  • 体重そのものではなく「平均からの離れ方」で見るようにした
  • 体重計に乗る頻度を、月4回から月10〜19回まで増やし、その後も月6〜8回で続けている
  • 何をしたかは別の記事に分けた（食事／走り方／シューズ）
