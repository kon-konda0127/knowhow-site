# なぜ重要か

これを読むと、画像生成の「毎回ちがう絵柄になる」問題を、道具ではなく手順で潰せることが分かる。

必要なのは図鑑そのものではなく、次も同じものが出る書き方を1つ持っておくことである。

# しくみ（なぜ効くか）

  • 画像生成は、同じ指示でも言葉が曖昧なほど揺れる。「おしゃれな絵」では毎回ちがうものが出る
  • 絵柄を言葉で分解して固定すると揺れが減る（線の太さ・面か線か・余白・色数・彩度など）
  • 図鑑は、その分解済みの言葉をあらかじめ並べておくもの。作りたい雰囲気から引ける
  • 投稿はもう1点挙げていた。参考になる画像を一緒に渡すと、言葉だけより寄りやすい

# うちの体制ではこう使う

実測1: 同じ問題を、共通指示で解いていた

記事の画像用の指示書に「共通の指示（毎回、先頭に貼る）」という節がある。そこに画風が言葉で固定してある。

> 画風: 落ち着いたフラットイラスト。線は細め、面で見せる。余白を多めに。色数は3〜4色＋アクセント1色

同じ指示書の末尾にも、狙いがはっきり書いてある。

> 同じ共通指示で作れば、シリーズとして並んだ時に統一感が出る（配色と画風を固定しているため）

投稿が図鑑で実現しようとしていることを、うちは共通指示の固定で実現していた。

実測2: 「選べる」ことは、うちでは価値にならない

図鑑は複数の絵柄から選ぶための道具である。うちの用途は記事の並びの統一なので、選択肢が増えるほど不利になる。

同じ「絵柄を安定させたい」でも、向きが逆になる場合がある。選ぶために揃えるのか、選ばないために固定するのか。うちは後者だった。

実測3: そもそも絵と図を使い分けている

同じ指示書に、こういう分け方も書いてある。

> 雰囲気・場面を伝えたい → 絵（画像生成AI）。意味・関係・数量を伝えたい → 図（自分で単一HTMLを書いてスクリーンショット）

理由は「AI画像の文字は崩れやすく、図はラベルが崩れると意味が通らない」から。文字を含む図は画像生成に任せず、自分で書いている。図鑑の効く範囲は、うちではさらに狭くなる。

実測4: 未実施の1点

「参考になる画像を一緒に渡す」はやっていない。言葉だけで固定している。

これは図鑑と違ってうちの用途と衝突しない（1つの絵柄に寄せるのに使える）。次に記事の画像を作る時に1回試す。現時点では未検証。

# よくあるミス・落とし穴

  • 「安定させたい」の中身を確かめずに道具を入れない。選ぶために揃えるのか、選ばないために固定するのかで、要るものが変わる
  • 図鑑は作った時点では効かない。効くのは「毎回それを貼る」運用のほうで、貼らなければ揃わない
  • 文字を含む画像を、画像生成に任せない。ラベルが崩れると意味が通らなくなる。うちは意味を伝える図だけ自分で書いている
  • 重複を「見送り」と書き残す。同じ問題を既に解いていると気づかないまま道具を増やすと、同じことを二重に持つことになる
