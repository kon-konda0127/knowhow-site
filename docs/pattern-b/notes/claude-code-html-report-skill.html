Claude Code HTML出力をコンサル品質に整えるスキル

カテゴリ: AI開発 > Claude Code活用 ｜ 更新: 2026-08-09

#ClaudeCode #スキル #HTML出力 #資料作成

Claude CodeにHTMLを出力させると、デフォルトでは「枠・グラデ・絵文字まみれ」になりがち。 このスキルを導入すると、コンサル資料レベルの整ったHTMLを一発で生成できるようになる。

ポイント

  • html-report-design スキル（AIに追加できる行動指針ファイル）を入れると「HTMLで出して」と指示した瞬間だけ自動的に働く
  • 枠・グラデーション・絵文字を禁止し、あらかじめ用意された完成済みCSSを使わせる
  • 各セクションは「見出し→結論1文→根拠」の順で強制される
  • 図解は矢羽根／ロードマップ／フレームワーク表／バブル／滝グラフの型から選ぶ
  • 配色は脇役グレー＋主役の濃紺1色、凡例なしの直接ラベル（視線が散らない）
  • アクセント色だけ会社カラーに差し替え可能
  • A4印刷でそのまま配布できるレベルのデザイン品質

インストール方法

  • ステップ1: CLIから npx skills add Ted0321/kotetsu-work-ai-skills@html-report-design を実行
  • ステップ2（別の方法）: Claude Codeに「github.com/Ted0321/kotetsu... の skills/html-report-design を ~/.claude/skills/ にインストールして」と1行貼るだけでもOK
  • ChatGPT派はSKILL.mdの内容をコピペしてカスタム指示に貼ることで同等の効果が得られる（※要確認）

よくあるミス・落とし穴

  • スキルなしで「HTMLで出して」と頼むと、枠・グラデ・絵文字まみれのスライド風になる
  • 仕組みはシンプル：AIが「線と箱」でビジュアルを作ろうとするのを、完成済みCSSで強制的に矯正している
