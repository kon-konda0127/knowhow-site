Codex subagent のモデルルーティング（model-router）

カテゴリ: AI開発 > Codex活用 ｜ 更新: 2026-08-09

#Codex #subagent #モデル選択 #コスト最適化

AIツールを使う時、すべての作業に最上位の高いモデルを使うのはコスト過多になりやすい。 model-routerを使うと「重い仕事は高いモデル、軽い仕事は安いモデル」に自動で振り分けられ、品質を落とさずにコストを下げられる。

ポイント

  • model-router というツールで Codex の subagent（AIが別のAIに指示を出す仕組み）機能を拡張できる
  • タスクごとに異なるモデルを自動で使い分けられる
  • 重い判断・設計は上位モデル（Opusなど）、定型的なコード生成は軽量モデル（DeepSeekなど）に振り分ける
  • コスト構造そのものが変わる発想：従来は全タスクに最上位モデルを使うのが普通だったが、それは過剰コストになりやすかった

インストール手順

  • ステップ1: model-router をインストール（※具体的なインストールコマンドは要確認）
  • ステップ2: subagent（AIが別のAIに指示を出す機能）のモデル設定で「選択したモデルすべて」を有効化する
  • ステップ3: 設定を保存して完了

よくあるミス・落とし穴

  • これまでは全タスクに同じ最上位モデルを使うのが普通だったが、それはコスト過多になりやすい
  • 軽量モデルに向かない作業（複雑な判断・設計）まで振り分けると品質が落ちるので注意（※実際の使用感は要確認）
