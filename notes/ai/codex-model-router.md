# Codex subagent のモデルルーティング（model-router）

カテゴリ: AI開発 > Codex活用
タグ: #Codex #subagent #モデル選択 #コスト最適化

## ポイント
- `model-router` というツールで Codex の subagent 機能を拡張できる
- タスクごとに異なるモデルを使い分けられる（Opus等の上位モデル ↔ DeepSeek等の軽量モデル）
- 重い判断・設計は上位モデル、定型的なコード生成は軽量モデル、という振り分けが可能
- コスト構造そのものが変わる発想

## インストール手順
1. model-router をインストール
2. subagent のモデル設定で「選択したモデルすべて」を有効化
3. 設定を保存して完了

## よくあるミス・落とし穴
- これまでは全タスクに同じ最上位モデルを使うのが普通だったが、それはコスト過多になりやすい
